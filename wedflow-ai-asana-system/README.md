# WedFlow AI — Asana Wedding Planning Operating System

## Overview
A full-scale AI-powered wedding planning system built in Asana Advanced to master:
- Product Management
- Workflow Architecture
- Automation
- AI Operations
- Stakeholder Coordination

## Core Features
- Wedding Master Plan
- Guest Size Estimation
- Wedding Priority Matrix
- Vendor Management
- Budget Tracking
- Cultural Requirement Mapping
- Timeline Planning

## AI Integration
- Asana AI for task generation
- ChatGPT for budgeting, vendor negotiation, and planning
- Automation workflows

## Objective
Transform wedding planning into a scalable operational management system.
